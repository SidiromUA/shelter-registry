# ЛР3. Перевірка доступності (WCAG 2.2)

## Інструменти

- **Lighthouse** — DevTools → Lighthouse → Accessibility → Analyze page load.
- **axe DevTools** — розширення для Chrome/Firefox.
- **WAVE** — https://wave.webaim.org (для сторінок, опублікованих в інтернеті).
- **Клавіатура** — пройдіть сторінку лише клавішами Tab / Shift+Tab / Enter / Space.
- **Екранний читач** — VoiceOver (macOS: Cmd+F5) або NVDA (Windows).

## Порушення у `web/inaccessible-example.html` та їх виправлення

| № | Порушення | Критерій WCAG | Виправлення (див. `index.html`, `add-shelter.html`) |
|---|---|---|---|
| 1 | Немає `<!DOCTYPE>`, `lang`, `<title>` | 3.1.1, 2.4.2 | `<html lang="uk">`, змістовний `<title>` |
| 2 | Меню з `<span onclick>` — недоступне з клавіатури | 2.1.1 | `<nav>` + `<a href>` |
| 3 | «Заголовки» з `<div style>` | 1.3.1 | `<h1>`, `<h2>` у правильній ієрархії |
| 4 | `<img>` без `alt` | 1.1.1 | `alt="..."` або `alt=""` для декоративних |
| 5 | Стан лише кольором (●) | 1.4.1 | Текст «Готове / Не готове» + колір |
| 6 | Сірий текст `#999` на білому (контраст 2,8:1) | 1.4.3 | Контраст не менше 4,5:1 |
| 7 | Поля форми без `<label>`, лише placeholder | 1.3.1, 3.3.2 | `<label for>` для кожного поля, підказки `aria-describedby` |
| 8 | Кнопка з `<div onclick>` | 4.1.2 | `<button type="submit">` |
| 9 | Невидимий фокус | 2.4.7 | `:focus-visible { outline: ... }` |
| 10 | Немає пропуску навігації | 2.4.1 | Посилання «Перейти до основного вмісту» |
| 11 | Помилки не оголошуються | 4.1.3 | `role="alert"` для помилок, `role="status"` для повідомлень |

## Результат для звіту

Зробіть знімки екрана звіту Lighthouse **до** і **після** виправлень (оцінка Accessibility)
та коротко опишіть кожне виправлення.
